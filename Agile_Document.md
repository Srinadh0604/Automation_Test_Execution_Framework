# Agile Document – Automated Test Execution Framework

## 1. Project Title
Automated Test Execution Framework

---

## 2. Project Overview
The Automated Test Execution Framework is designed to automate the testing of web applications to ensure functional accuracy, reliability, and consistency. The framework was developed over a period of two months using Selenium WebDriver, TestNG, Maven, and REST API testing. The primary goal of the project is to reduce manual testing effort and enable efficient, repeatable test execution.

In the final phase of the project, a lightweight Spring Boot application with a user interface was integrated to demonstrate and trigger automated test execution during evaluation and panel discussions. The core focus of the project remains on automation framework development.

---

## 3. Agile Methodology Used
The project follows the Agile methodology with a sprint-based development approach. The overall work was divided into multiple sprints, each focusing on specific goals such as framework design, automation implementation, API testing, execution, and final integration. Continuous improvements and testing were carried out at the end of every sprint.

---

## 4. Sprint-Wise Execution Details

### Sprint 1 (10 December 2025 – 20 December 2025)
- Requirement analysis for automated testing framework  
- Understanding application under test  
- Selection of automation tools and technologies  
- Framework architecture planning  
- GitHub repository creation  

---

### Sprint 2 (21 December 2025 – 05 January 2026)
- Selenium WebDriver setup  
- TestNG framework configuration  
- Maven project configuration  
- Browser initialization and base test setup  
- Common utility classes implementation  

---

### Sprint 3 (06 January 2026 – 15 January 2026)
- Page Object Model (POM) implementation  
- Development of reusable page classes  
- Writing automated test cases for web application  
- Handling waits, validations, and exceptions  
- Test data handling  

---

### Sprint 4 (16 January 2026 – 25 January 2026)
- REST API testing implementation  
- TestNG XML suite creation  
- Maven-based test execution  
- Report generation  
- Bug fixing and framework optimization  

---

### Sprint 5 (26 January 2026 – 28 January 2026)
- Integration of automation framework with Spring Boot (mentor-driven)  
- UI added to trigger and demonstrate automated test execution  
- End-to-end execution validation  
- Documentation preparation  
- Final milestone submission

## 6. Final Outcome
The Automated Test Execution Framework was successfully developed following Agile principles. The framework supports structured and reusable automated test execution for web applications and APIs. The integration of a Spring Boot UI in the final phase enables easy demonstration of test execution during evaluation. The project is scalable, maintainable, and suitable for real-world automation testing scenarios.
