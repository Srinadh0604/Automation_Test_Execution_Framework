# Automated Test Execution Framework

## 📌 Project Overview
The Automated Test Execution Framework is designed to automate the testing of web applications to ensure functional correctness, reliability, and efficiency. The framework was developed over a period of two months using industry-standard automation tools and follows a modular and maintainable design.

The primary focus of this project is automation testing, including UI automation and REST API testing. In the final phase of the project, a lightweight Spring Boot application with a user interface was integrated to demonstrate and trigger automated test execution during evaluation and panel discussions.

---

## 🎯 Project Objectives
- Reduce manual testing effort  
- Enable reusable and maintainable automation scripts  
- Support automated execution of UI and API test cases  
- Provide reliable and repeatable test execution  
- Demonstrate automation execution flow clearly during evaluation

## ▶️ How to Execute Automated Tests

### Prerequisites
- Java installed  
- Maven installed  
- Browser drivers configured (ChromeDriver or others as applicable)

### Steps to Run Tests
1. Clone the repository  
2. Open the project in an IDE  
3. Navigate to the project root  
4. Run the following command:
   mvn test

 5. Tests will execute based on TestNG configuration
